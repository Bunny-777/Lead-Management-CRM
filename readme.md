# Lead Management System

## Overview
This project is a CRM-style Lead Management System developed using Core PHP and MySQL. It allows administrators to manage leads, assign them to users, track lead status, and generate reports.

## Features

### Admin
- Login Authentication
- Dashboard
- Manage Countries
- Manage States
- Manage Cities
- Manage Users
- Manage Lead Types
- Manage Lead Status
- Create Leads
- Assign Leads to Users
- View Reports

### User
- Secure Login
- Dashboard
- Create Lead
- View Assigned Leads
- Upload Additional Documents
- *Note: Users cannot edit or delete submitted leads.*

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, Bootstrap, JavaScript

## Database

**Tables:**
- `users`
- `countries`
- `states`
- `cities`
- `lead_types`
- `lead_status`
- `leads`
- `lead_documents`
